# Финансы без сахара

Помогай пользователю сопровождать существующий сайт, сохраняя его поведение и оформление. Применяй только действия, необходимые для текущего поручения. Сам вызов навыка без конкретного задания означает ознакомление с проектом, а не разрешение обновлять данные или публиковать сайт.

## Сначала прочитай

Корень проекта — папка с index.html, README.md и PROJECT.md, на три уровня выше этой папки навыка. Команды ниже выполняются из корня.

- [README.md](../../../README.md) — описание для сдачи, запуск и размещение.
- [PROJECT.md](../../../PROJECT.md) — подробные сценарии разделов и ограничения.
- [AGENTS.md](../../../AGENTS.md) — предпочтения пользователя и правила работы с данными. Прочитай его и при работе в Claude Code.
- Для конкретной правки прочитай затрагиваемые файлы. Код и результаты текущей проверки важнее старых планов и сохранённых отчётов.

Общайся по-русски, объясняй действия простыми словами. Перед правкой кратко назови план. Выполняй уже порученную работу без повторного согласования; расширение задачи, удаление и переименование файлов согласуй отдельно. Не обращайся к Notion и не отправляй клиентские данные внешним сервисам.

## Устройство репозитория

Основные разделы — HTML, CSS и обычный JavaScript без сборки. Общая нумерация суда использует api/court-counter.php (PHP 7.4+, PDO SQLite). Локальный index.html работает с прежним счётчиком браузера; npm и фреймворк для запуска не нужны.

| Путь | Назначение |
|---|---|
| index.html | Страница, формы и порядок подключения скриптов |
| css/style.css | Единое оформление и адаптация под телефон |
| js/utils.js | Общие функции window.U, даты, ссылки и localStorage |
| js/rates.js, data/rates.js | USD/EUR, история, графики и CSV |
| js/deadlines.js, data/deadlines.js | Налоговые сроки |
| js/news.js, data/news.js, data/archive.js | Выпуск и недельный архив |
| js/events.js, data/events*.js | Праздники и картинки к ним |
| js/humor.js, data/humor.js | Картинки дня, сохранённые этапы очереди, общее окно просмотра изображений |
| js/calc.js | Калькулятор, НДС, история и выбранный курс |
| js/court.js, js/court-sound.js, data/court*.js | Финансовый суд, звук, виды покупок, бренды и реплики |
| update-rates.ps1, update-humor.ps1 | Обновление истории курсов и списка с очередью картинок |

| api/court-counter.php | Общий счётчик; база nosugarfin-private/court.sqlite вне public_html |

| .claude/, .agents/, AGENTS.md, logs/ | Локальные инструкции и исторические журналы |

Порядок скриптов в index.html важен: utils — первым; данные — перед использующей их логикой; курсы — до калькулятора и суда; humor с window.openLightbox — до events и суда; court.js — до court-sound.js, чтобы звук прочитал настройки после однократного сброса; court-kinds — после остальных реплик суда. Графики используют Chart.js с внешнего CDN.

## Локальный запуск

Открой index.html в современном браузере. Для запуска сервера или установки зависимостей оснований нет. Если поручено открыть страницу на Windows, используй доступный инструмент браузера или Start-Process с абсолютным путём в рамках разрешений среды. Если запуск GUI недоступен, дай пользователю путь к index.html.

Для свежих сетевых данных и загрузки Chart.js нужен интернет. История и настройки привязаны к адресу сайта и браузеру: переход с локального файла на домен не переносит их автоматически.

## Изменения

1. Найди обработчик раздела, его данные и разметку; не переделывай соседние разделы ради локальной правки.
2. Перед изменениями суда запусти его существующую проверку. После правки повтори её и проверь новые примеры покупок, если менялась классификация.
3. Для остальных изменений подбери проверку по затронутому поведению. Для одной правки README достаточно перечитать результат и проверить ссылки.
4. Обнови описание изменённого поведения в PROJECT.md; README меняй, если затронуты возможности, запуск, обновления или публикация.

Сохраняй следующие правила:

- Горящие сроки видны при наличии сроков сегодня или в ближайшие семь дней. Сегодняшняя карточка показывается только для сегодняшних сроков; недельный список изначально свёрнут. Если оба списка пусты, скрываются раздел и ссылка меню.
- У суда вид покупки определяется через группы и C.kinds. Смешанную группу разделяй, если новый вид подходит не всем её предметам. Текстиль использует «Старое износилось» и «Будете ли пользоваться этим через полгода?», одежда сохраняет вопрос о ношении.
- Текстовые фильтры видов покупок в js/court.js и tests/court-test.js должны оставаться согласованными. Протест стороны и ответ судьи «Протест принят» — разные события; не определяй протест только по слову без учёта говорящего.
- Юмор показывает две картинки в день в общем для читателей порядке. Каждый файл повторяется только после остальных. update-humor.ps1 сохраняет HUMOR_ROTATIONS: новые файлы встраиваются перед повтором, не раньше следующего дня. Не сбрасывай очередь при обычном /news, не редактируй её вручную.
- Не удаляй старую историю курсов и не исправляй data/rates.js вручную вместо скрипта. Учитывай формат чисел ru-RU и фактическую дату действия курса.
- Последнее слово: постоянный порядок типов кнопок — honest, plead, surrender. Честный довод даёт −1 балл, просьба с равной вероятностью −1 или +1, «суду виднее» ограничивает строгость условным решением. Итог зависит от исходных ответов; кнопки не соответствуют трём фиксированным приговорам.
- Не очищай пользовательский localStorage при проверке. Используй отдельный профиль браузера, как в штатном тесте.
- PowerShell 5.1: файлы .ps1 с кириллицей сохраняй в UTF-8 с BOM. Не предполагай наличие Python; сначала проверяй окружение.

## Обновление данных

Обновляй данные только в рамках соответствующего поручения. Сетевые команды из корня:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File update-rates.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File update-humor.ps1
```

Для /news прочитай соседний [.claude/skills/news/SKILL.md](../news/SKILL.md) и следуй его порядку: обновление данных, поиск, проверка, черновик, запись новостей и архива после «ок». Создание этого навыка не заменяет news.

Задание Windows отключено. run-news.ps1 — безопасная заглушка. Не возвращай расписание и автоматический выпуск без нового прямого поручения.

## Проверки ошибок

Основная команда из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-tests.ps1
```

Для проверки случайных сценариев, когда это оправдано:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-tests.ps1 -Cases 300
```

Проверка использует Edge с отдельным временным профилем. Результат — tests/last-report.txt и код выхода. При запрете среды на запуск или файловую операцию не обходи ограничения. Перед повторным запуском учитывай, что тест удаляет свою временную папку fin-no-sugar-test: проверяй её разрешённый абсолютный путь.

При ошибке изучи соседние реплики и условия сценария. Отличай дефект поведения от ложного срабатывания проверки. Не объявляй проблему решённой только потому, что случайный повторный прогон прошёл: добавь воспроизводимый контрольный пример для причины ошибки.

Если доступен Node.js, используй node --check для изменённых .js; если его нет, проверяй синтаксис в доступном браузере, не устанавливая инструменты без необходимости. Для разметки проверь существование локальных src/href, уникальность id и совпадение регистра путей — на хостинге Linux регистр имеет значение.

Для проверки мобильного оформления в Edge headless используй временную страницу с iframe шириной 360/390/430 px: узкое окно headless может давать ложное обрезание. Дай завершиться анимации заголовка. Для интерактивных проверок Chart.js учитывай особенности requestAnimationFrame при виртуальном времени.

Проверка счётчика и сброса на искусственных данных: `node tests/court-counter-test.js ПУТЬ-К-php.exe`. Без аргумента проверяется только клиент; серверная проверка запускает временный PHP с PDO SQLite и отдельной базой.

## Подготовка публикации

Поручение подготовить архив не означает поручение загрузить его на хостинг. Сначала подготовь проверяемый локальный результат; внешнюю загрузку выполняй только в рамках явно данного поручения и доступных разрешений.

Публичный состав — index.html и папки css/, js/, data/, pictures/, sounds/, api/. Проверь, что здесь нет ключей, клиентских сведений и личных файлов; использование изображений для открытой публикации должно быть разрешено.

Общий счётчик: при начале заседания выдаёт номер ГГММДД-NNN (дата и общий порядковый номер без сброса по дням); повтор того же запроса не увеличивает счёт. Покупки и личный архив на сервер не отправляются. База nosugarfin-private/court.sqlite создаётся рядом с public_html, требует права записи PHP и должна сохраняться при обновлениях и в резервных копиях. Не включай её в публичный ZIP. При обновлении загрузить сначала api/court-counter.php, затем js/court.js и index.html; обновлять версию ссылки на скрипт для обхода старого кэша. После выкладки проверить счётчик и начало заседаний с двух устройств. Елена подтвердила общую нумерацию на компьютере; последнее обновление с полным сбросом на хостинге пока не подтверждено. GET новой версии обработчика при первом запросе выполняет согласованный серверный сброс — это не просто проверка без изменений.

По прямому поручению Елены 04.11.2026 подготовлен полный однократный сброс суда: все ключи court-* в браузере и серверная нумерация. Маркер court-full-reset-20261104-v1 в браузере и таблице migrations базы предотвращает повторный сброс новых данных. Не менять этот маркер при обычных обновлениях. Звук подключается после js/court.js, чтобы загрузить настройки уже после очистки. Включение: загрузить api/court-counter.php, js/court.js и index.html; данные пользователей очищаются при открытии обновлённого сайта.

Для ZIP:

- Используй явный список публичных путей, не архивируй весь репозиторий.
- index.html должен лежать прямо в корне ZIP; внутри ZIP используй разделитель /.
- Не включай .claude/, .agents/, AGENTS.md, README.md, PROJECT.md, logs/, tests/, .git, .ps1 и другие ZIP.
- Не перезаписывай старый архив без необходимости: выбери новое имя nosugarfin-upload-ДАТА.zip или добавь суффикс, если файл уже есть.
- После создания открой список содержимого архива и проверь состав и обязательные файлы. Архивы nosugarfin-upload-*.zip уже исключены из коммитов через .gitignore.

Целевая папка хостинга — public_html сайта nosugarfin.ru. При ручной загрузке сохрани относительную структуру, после распаковки проверь страницу, ресурсы, калькулятор и суд. ZIP на сервере после распаковки не нужен. Сертификат и подключение домена проверяются отдельно; покупка хостинга сама по себе их работу не подтверждает.
